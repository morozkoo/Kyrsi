ПОЯСНЕНИЕ К ЛАБОРАТОРНОЙ РАБОТЕ

Тема: REST API для конвертации валют на Node.js и Express.js


1. ЧТО НУЖНО БЫЛО СДЕЛАТЬ

В этой лабораторной работе создается серверное приложение. Сервер принимает запросы от браузера, Postman или будущего React-приложения и возвращает ответы в формате JSON.

Предметная область проекта — конвертация валют. Сервер умеет:

- показывать список валют;
- показывать одну валюту по коду;
- добавлять валюту;
- изменять валюту;
- удалять валюту;
- переводить сумму из одной валюты в другую;
- загружать курсы валют с сайта Центрального банка РФ.

Данные пока хранятся в массиве в памяти. Поэтому после перезапуска сервера добавленные или измененные валюты возвращаются к исходным значениям.


2. ЧТО ТАКОЕ NODE.JS

Node.js позволяет запускать JavaScript не только в браузере, но и на сервере. Благодаря Node.js файл server.js может принимать HTTP-запросы и отправлять ответы клиенту.

npm — менеджер пакетов Node.js. Через него устанавливаются библиотеки и запускаются команды проекта.

Основные команды:

npm install
    Устанавливает библиотеки из package.json.

npm run dev
    Запускает сервер в режиме разработки через nodemon.

npm start
    Запускает сервер обычным способом.

Если PowerShell не видит npm, нужно закрыть старый терминал VS Code и открыть новый. В текущем проекте используется порт 3001, потому что порт 3000 занят другим приложением.


3. ЧТО ТАКОЕ EXPRESS.JS

Express.js — библиотека для Node.js, которая упрощает создание сервера и маршрутов.

В package.json подключены:

- express — создание HTTP-сервера и маршрутов;
- fast-xml-parser — разбор XML-ответа Центрального банка РФ;
- nodemon — автоматический перезапуск сервера при изменении файлов.

5. КАК РАБОТАЕТ server.js

Сначала подключаются Express и файлы маршрутов:

const express = require('express');
const currencyRoutes = require('./routes/currencyRoutes');
const { convertCurrency } = require('./controllers/currencyController');

require подключает другой JavaScript-файл или библиотеку.

Затем создается приложение:

const app = express();
const port = process.env.PORT || 3001;

app — это серверное приложение Express.
port — порт, на котором сервер принимает запросы. Если переменная PORT не задана, используется 3001.


6. MIDDLEWARE

Middleware — промежуточная функция, которая обрабатывает запрос до передачи его маршруту.

app.use(express.json());

Эта строка позволяет серверу читать JSON в теле POST и PUT-запросов. Например:

{
  "from": "USD",
  "to": "RUB",
  "amount": 100
}

Без express.json() сервер не сможет нормально прочитать req.body.

Строка express.urlencoded() позволяет принимать данные в формате URL-encoded.


7. КАК РАБОТАЮТ МАРШРУТЫ

Маршрут состоит из HTTP-метода и URL.

GET используется для получения данных.
POST используется для создания данных или запуска операции.
PUT используется для полного обновления данных.
DELETE используется для удаления данных.

Основные маршруты проекта:

GET http://localhost:3001/
    Проверяет, что API запущено.

GET http://localhost:3001/currencies
    Возвращает список всех валют.

GET http://localhost:3001/currencies/USD
    Возвращает одну валюту с кодом USD.

POST http://localhost:3001/currencies
    Добавляет новую валюту.

PUT http://localhost:3001/currencies/GBP
    Полностью обновляет валюту GBP.

DELETE http://localhost:3001/currencies/GBP
    Удаляет валюту GBP.

POST http://localhost:3001/conversions
    Выполняет конвертацию.

POST http://localhost:3001/currencies/refresh
    Загружает актуальные курсы из API ЦБ РФ.


8. КАК РАБОТАЕТ КОНВЕРТАЦИЯ

Для запроса POST /conversions передаются три значения:

{
  "from": "USD",
  "to": "RUB",
  "amount": 100
}

from — исходная валюта.
to — целевая валюта.
amount — сумма для конвертации.

Для каждой валюты хранится курс rateToRub — сколько рублей стоит одна единица валюты.

Формула:

курс конвертации = курс исходной валюты в рублях / курс целевой валюты в рублях
результат = сумма * курс конвертации

Например, если USD равен 92.5 RUB, то 100 USD превращаются в 9250 RUB.

Ответ сервера:

{
  "from": "USD",
  "to": "RUB",
  "amount": 100,
  "rate": 92.5,
  "result": 9250
}


9. КАК РАБОТАЕТ CRUD

CRUD — это четыре основные операции с данными:

Create — создание, в проекте POST /currencies.
Read — чтение, в проекте GET /currencies и GET /currencies/:id.
Update — изменение, в проекте PUT /currencies/:id.
Delete — удаление, в проекте DELETE /currencies/:id.

Пример POST /currencies:

{
  "id": "GBP",
  "name": "Фунт стерлингов",
  "symbol": "£",
  "rateToRub": 118.4
}

В ответ сервер возвращает созданный объект и статус 201.


10. ПАРАМЕТР :id

Запись /currencies/:id означает, что id — динамическая часть URL.

В запросе:

GET /currencies/USD

значение req.params.id равно USD.

Сервер ищет валюту с таким кодом в массиве. Если валюта найдена, возвращается статус 200. Если нет — статус 404.


11. ОБРАБОТКА ОШИБОК

Статус 200 означает успешный запрос.
Статус 201 означает, что объект создан.
Статус 204 означает успешное удаление без тела ответа.
Статус 400 означает неправильные данные запроса.
Статус 404 означает, что маршрут или валюта не найдены.
Статус 500 означает внутреннюю ошибку сервера.

Например, если отправить неизвестную валюту:

GET /currencies/ABC

сервер вернет:

{
  "error": "Валюта не найдена"
}

Если JSON запроса составлен неправильно, сервер вернет статус 400 и сообщение:

{
  "error": "Некорректный JSON в теле запроса"
}


12. КАК ПОЛУЧАЮТСЯ КУРСЫ ЦБ РФ

Маршрут POST /currencies/refresh отправляет запрос на адрес:

https://www.cbr.ru/scripts/XML_daily.asp

ЦБ РФ возвращает данные в формате XML. Библиотека fast-xml-parser преобразует XML в JavaScript-объект. После этого сервер находит знакомые валюты и обновляет их rateToRub.

Курсы сохраняются только в памяти. В следующей лабораторной работе массив можно заменить базой данных.


13. КАК ПРОВЕРЯТЬ API В POSTMAN

1. Запустить сервер:

npm run dev

2. Открыть Postman.
3. Выбрать метод GET.
4. Ввести URL, например:

http://localhost:3001/currencies

5. Нажать Send.
6. Проверить статус и JSON-ответ.

Для POST и PUT нужно открыть вкладку Body, выбрать raw и JSON, затем вставить тело запроса.

Пример для POST /conversions:

URL:
http://localhost:3001/conversions

Body:

{
  "from": "USD",
  "to": "RUB",
  "amount": 100
}

На скриншоте должны быть видны метод, URL, тело запроса, статус ответа и результат.


14. ЧТО СКРИНШОТИТЬ ДЛЯ ОТЧЕТА

1. Терминал с сообщением о запуске сервера.
2. GET / — проверка API.
3. GET /currencies — список валют.
4. GET /currencies/USD — одна валюта.
5. POST /currencies — создание валюты, статус 201.
6. PUT /currencies/GBP — обновление валюты, статус 200.
7. POST /conversions — результат конвертации.
8. POST /currencies/refresh — обновление курсов ЦБ РФ.
9. DELETE /currencies/GBP — удаление, статус 204.
10. GET /currencies/UNKNOWN — ошибка 404.


15. ЧТО СКАЗАТЬ НА ЗАЩИТЕ

В работе создан REST API на Node.js и Express.js для предметной области конвертации валют. Реализованы CRUD-операции над валютами, отдельный маршрут конвертации и обновление курсов из API ЦБ РФ. Для обработки запросов используются middleware Express. Данные пока хранятся в массиве, а в следующих работах могут быть перенесены в базу данных. React-клиент и графики будут подключаться к этому API на следующем этапе.
