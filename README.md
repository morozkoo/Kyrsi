# Currency Converter API

Учебное REST API для приложения конвертации валют и расчёта курсов. Данные временно хранятся в массиве в памяти сервера.

## Запуск

```bash
npm install
npm run dev
```

Сервер запускается на `http://localhost:3001` по умолчанию. Порт можно изменить через переменную окружения `PORT`.

## Маршруты

| Метод | URL | Назначение |
| --- | --- | --- |
| GET | `/currencies` | Получить все валюты |
| POST | `/currencies/refresh` | Загрузить актуальные курсы из ЦБ РФ |
| GET | `/currencies/:id` | Получить валюту по коду |
| POST | `/currencies` | Добавить валюту |
| PUT | `/currencies/:id` | Полностью обновить валюту |
| DELETE | `/currencies/:id` | Удалить валюту |
| POST | `/conversions` | Выполнить конвертацию по текущим курсам |

Пример запроса конвертации:

```json
{
  "from": "USD",
  "to": "RUB",
  "amount": 100
}
```

До первого вызова `/currencies/refresh` используются стартовые значения в памяти. После обновления актуальные значения из XML ЦБ РФ сохраняются в массиве до перезапуска сервера.
