# Конвертер валют — лабораторная 7

Откройте ветку `27`. Для запуска нужен Node.js 22.12+ и работающий PostgreSQL с базой проекта. Настройки берутся из `лаб1/.env`. Если файла ещё нет, скопируйте `.env.example` и укажите свои `DATABASE_URL` и `JWT_SECRET`. На чистой базе выполните `npm run db:migrate` и `npm run db:seed` из папки сервера. MongoDB нужна для API предыдущей лабораторной.

В первом терминале из корня репозитория:

```powershell
cd лаб1
npm ci
npm start
```

Во втором терминале из корня репозитория:

```powershell
cd лаб1/лаба4
npm ci
npm run dev
```

Откройте адрес, показанный Vite. Клиент по умолчанию подключается к `http://localhost:3001`. Если у сервера другой `PORT`, задайте `VITE_API_URL` с этим адресом перед запуском Vite. Если в серверном `.env` задан `CLIENT_ORIGIN`, добавьте туда фактический адрес Vite.

В двух вкладках найдите раздел «Обсуждение курсов», введите разные имена и войдите в одну валютную комнату. Отправьте сообщение и проверьте, что оно появилось в обеих вкладках. Переключите вторую вкладку на другую валюту и проверьте уведомление о выходе и изоляцию сообщений. При закрытии вкладки оставшиеся участники получают уведомление и обновлённый счётчик.

Чат использует гостевые имена. В каждой вкладке отображается до 100 событий текущей комнаты. После смены комнаты, выхода или обновления страницы список очищается.
