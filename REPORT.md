## 1. Цель работы

Приобрести практические навыки создания серверного приложения на платформе Node.js с использованием фреймворка Express.js, изучить маршрутизацию и обработку HTTP-запросов методов GET, POST, PUT и DELETE, а также реализовать REST API для последующей интеграции с клиентской частью приложения.

## 2. Постановка задачи

Для предметной области «Приложение для конвертации валют и расчета курсов» необходимо разработать серверное приложение, которое позволяет:

- получать список доступных валют;
- получать сведения об одной валюте;
- добавлять, изменять и удалять валюты;
- выполнять конвертацию денежных сумм;
- загружать актуальные курсы валют из API Центрального банка Российской Федерации;
- возвращать корректные HTTP-статусы и сообщения об ошибках.

## 3. Краткое описание проекта

Проект реализован на Node.js с использованием Express.js. На начальном этапе данные хранятся в массиве в памяти сервера. Для получения актуальных курсов используется XML-сервис ЦБ РФ `https://www.cbr.ru/scripts/XML_daily.asp`. После загрузки значения курсов обновляются в памяти до перезапуска сервера.

Структура проекта:

```text
currency-converter-api/
├── controllers/
│   └── currencyController.js
├── data/
│   └── currencies.js
├── routes/
│   └── currencyRoutes.js
├── server.js
├── package.json
└── README.md
```

В сервере подключены middleware `express.json()` для обработки JSON и `express.urlencoded()` для обработки URL-encoded данных. Порт по умолчанию — `3001`, поскольку порт `3000` занят другим локальным приложением.

## 4. Листинг файла `server.js`

Ниже приведены основные части файла `server.js`.

### Подключение Express и маршрутов

```javascript
const express = require('express');
const currencyRoutes = require('./routes/currencyRoutes');
const { convertCurrency } = require('./controllers/currencyController');

const app = express();
const port = process.env.PORT || 3001;
```

### Middleware и корневой маршрут

```javascript
app.use(express.json());
app.use(express.urlencoded({ extended: true }));

app.get('/', (req, res) => {
  res.json({
    name: 'Currency Converter API',
    endpoints: ['GET /currencies', 'POST /conversions']
  });
});
```

### Подключение маршрутов

```javascript
app.use('/currencies', currencyRoutes);
app.post('/conversions', convertCurrency);
```

### Обработка ошибок и запуск сервера

```javascript
app.use((req, res) => {
  res.status(404).json({ error: 'Маршрут не найден' });
});

app.use((error, req, res, next) => {
  if (error instanceof SyntaxError && error.status === 400 &&
      error.type === 'entity.parse.failed') {
    return res.status(400).json({
      error: 'Некорректный JSON в теле запроса'
    });
  }

  console.error(error);
  res.status(500).json({ error: 'Внутренняя ошибка сервера' });
});

app.listen(port, () => {
  console.log(`Server running on http://localhost:${port}`);
});
```

## 5. Таблица маршрутов API

| Метод | Маршрут | Назначение | Успешный статус | Пример запроса | Пример ответа |
|---|---|---|---:|---|---|
| GET | `/` | Проверка доступности API | 200 | `GET /` | `{"name":"Currency Converter API",...}` |
| GET | `/currencies` | Получение всех валют | 200 | `GET /currencies` | `[ { "id": "USD", "rateToRub": 92.5 } ]` |
| GET | `/currencies/:id` | Получение валюты по коду | 200 | `GET /currencies/USD` | `{ "id": "USD", "name": "Доллар США", "rateToRub": 92.5 }` |
| POST | `/currencies` | Добавление валюты | 201 | JSON с `id`, `name`, `rateToRub` | Созданный объект валюты |
| PUT | `/currencies/:id` | Полное обновление валюты | 200 | `PUT /currencies/USD` + JSON | Обновленный объект |
| DELETE | `/currencies/:id` | Удаление валюты | 204 | `DELETE /currencies/USD` | Пустой ответ |
| POST | `/conversions` | Конвертация валюты | 200 | JSON с `from`, `to`, `amount` | `{ "result": 9250, "rate": 92.5 }` |
| POST | `/currencies/refresh` | Обновление курсов из ЦБ РФ | 200 | `POST /currencies/refresh` | Объект с `updated`, `source`, `currencies` |

### Примеры запросов

Добавление валюты:

```json
{
  "id": "GBP",
  "name": "Фунт стерлингов",
  "symbol": "£",
  "rateToRub": 118.4
}
```

Обновление валюты:

```json
{
  "name": "Доллар США",
  "symbol": "$",
  "rateToRub": 93.1
}
```

Конвертация:

```json
{
  "from": "USD",
  "to": "RUB",
  "amount": 100
}
```

Пример успешного ответа конвертации:

```json
{
  "from": "USD",
  "to": "RUB",
  "amount": 100,
  "rate": 92.5,
  "result": 9250,
  "source": "Внутренний учебный набор курсов; готов к замене на API ЦБ РФ"
}
```

| Ситуация | Статус | Пример ответа |
|---|---:|---|
| Валюта не найдена | 404 | `{ "error": "Валюта не найдена" }` |
| Маршрут не найден | 404 | `{ "error": "Маршрут не найден" }` |

| Неверный JSON | 400 | `{ "error": "Некорректный JSON в теле запроса" }` |
| Непредвиденная ошибка сервера | 500 | `{ "error": "Внутренняя ошибка сервера" }` |

## 8. Ответы на контрольные вопросы

### 1. Что такое Node.js?

Node.js — программная платформа для выполнения JavaScript вне браузера. Она использует движок V8 и позволяет создавать серверные приложения, работающие с файлами, сетью и HTTP-запросами.

### 2. Что такое Express.js?

Express.js — минималистичный веб-фреймворк для Node.js. Он упрощает создание HTTP-сервера, регистрацию маршрутов и подключение middleware.

### 3. Что такое REST API?

REST API — интерфейс взаимодействия между клиентом и сервером через HTTP-методы и адреса ресурсов. В данной работе ресурсом является коллекция валют `/currencies`.

### 4. Для чего используются HTTP-методы GET, POST, PUT и DELETE?

- `GET` получает данные;
- `POST` создает новый объект или запускает операцию;
- `PUT` полностью обновляет существующий объект;
- `DELETE` удаляет объект.

### 5. Что такое middleware?

Middleware — функция, которая получает запрос, ответ и функцию перехода к следующему обработчику. В проекте middleware используются для разбора JSON, обработки URL-encoded данных и ошибок.

### 6. Где хранятся данные в текущей версии проекта?

Данные хранятся в массиве `data/currencies.js` в памяти сервера. После перезапуска сервера изменения теряются.

### 7. Какие HTTP-статусы использует приложение?

Приложение использует `200` для успешного получения и обновления, `201` для создания, `204` для удаления без тела ответа, `400` для неверных данных, `404` для отсутствующих ресурсов и `500` для непредвиденных ошибок.

### 8. Как приложение получает курсы ЦБ РФ?

При запросе `POST /currencies/refresh` сервер выполняет HTTP-запрос к XML-сервису ЦБ РФ, разбирает XML с помощью `fast-xml-parser` и обновляет курсы найденных валют.
